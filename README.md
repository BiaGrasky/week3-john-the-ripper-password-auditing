Week 3 - Password Auditing with John the Ripper
Overview
A controlled cybersecurity internship lab project completed during Week 3 with NetworkWalks.
Activities
Introduction to password auditing
Using John the Ripper in an authorized lab
Understanding password-hash auditing concepts
Recording and documenting lab observations
Purpose
The project was designed to demonstrate how password auditing tools can be used in a controlled environment to understand password security.
Lab Safety
John the Ripper was used only against authorized lab data. This repository does not contain real passwords, password hashes, credentials, or unauthorized targets.
